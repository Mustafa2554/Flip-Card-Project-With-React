# Flip Card Project With React

An interactive flashcard learning application built with React. Flip cards to reveal answers and make learning concepts easier and more engaging.

## ✨ Features

- **Interactive Flashcards:** Display questions on the front and answers on the back.
- **3D Flip Effect:** Smooth card-flipping animation using CSS.
- **Hover Interaction:** Reveal answers by hovering over a card.
- **Reusable Components:** Render multiple cards using React components.
- **Dynamic Content:** Load flashcard questions and answers from a JavaScript data array.
- **Responsive Design:** A modern learning interface styled with CSS.
- **Keyboard Focus:** Cards include `tabIndex` to support keyboard focus.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- CSS3
- Vite

## 📸 How It Works

1. Each card displays a question on its front side.
2. Hover over a card to trigger the flip animation.
3. The answer appears on the back of the card.
4. Move the pointer away to return to the question.
